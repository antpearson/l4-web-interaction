Key Takeaways

  • Text inputs are for single-line text entry
  • Password inputs hide the text for security
  • Email inputs validate email format automatically
  • Radio buttons allow selecting ONE option from a group (same name attribute)
  • Checkboxes allow selecting MULTIPLE options
  • Select dropdowns provide a compact way to choose from many options
  • Textarea is for multi-line text input
  • Fieldsets & Legends group related form elements together
  • Labels should always be linked to inputs using for/id attributes
  • Required attribute makes fields mandatory
  • Placeholder shows hint text inside input fields
