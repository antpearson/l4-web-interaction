Structure Diagrams

Structure diagrams are really simple diagrams and, as the name suggests, a way of visually showing the structure of your website. These are simple diagrams that can quickly convey to a client how many pages your website contains and how it is possible to link between those pages.

What is a Structure Diagram?

A structure diagram shows:

  • All the pages in your website
  • How pages link to each other (navigation hierarchy)
  • The home page (usually at the top)
  • Secondary pages beneath it

Designing Usable Websites - Don't Make Me Think!

"Don't Make Me Think" is a famous book by Steve Krug about web usability. The core principle is simple: a good website should be so intuitive that users don't have to think about how to use it.

Key Usability Principles

  • Clarity is king - Don't make users guess what things do or where to find information
  • Minimize cognitive load - Don't make users think harder than necessary
  • Follow conventions - Users expect certain things to work in certain ways (e.g., logo in top left links to homepage)
  • Visual hierarchy - Important things should look important
  • Clickable things should look clickable - Buttons should look like buttons

Mobile Design Considerations

Where many students have tended to get it wrong in the past is at mobile device size. Consider these important points:

Mobile Design Checklist

  • Text size: Imagine holding your phone with your design on it. Could you read the text without moving your phone 3 inches away from your eyeballs? If no, increase text size (minimum 16px for body text)
  • Touch targets: Buttons, navigation, and CTAs (Call To Actions) should be big enough to be clicked accurately with your finger (minimum 44x44 pixels)
  • No hover effects: Remember that hover/rollover effects don't exist on phones - plan your interactions accordingly
  • Scrolling is fine: Mobile users are comfortable scrolling - don't try to cram everything above the fold
  • Simplify navigation: Use a hamburger menu for mobile rather than trying to fit all navigation items

Responsive Design Principles

Remember: everyone should get to see the same content regardless of device. The layout changes, but the content remains the same.

Adapting Layout to Suit Device Type

There are no hard and fast rules here - most considerations should be common sense. You will definitely need to design for a mobile device and a desktop device. Depending on the complexity of your design, you might want to do variations for tablet too.

Example: Attractions Grid

If you had a page showing all your rides/attractions:

  • Mobile: Images might be stacked singly (or perhaps two across)
  • Tablet: You may choose to have three across
  • Desktop: Four or more across

The same content, just rearranged to make best use of the available screen space.

What is Figma?

Figma is a powerful, free design tool used by professional designers and developers worldwide to create website and app designs. Unlike traditional design software, Figma runs entirely in your web browser, which means:

  • No installation required - works on any computer with internet access
  • Automatic saving - your work is saved to the cloud as you go
  • Real-time collaboration - multiple people can work on the same design
  • Access anywhere - work from university, home, or anywhere
  • Free for students - full access to all features

Figma Basics - Essential Tools

Key Tools You'll Use

1. Move Tool (V)

Select and move objects around. This is your default tool. Click any element to select it, then drag to move.

2. Frame Tool (F)

Create frames for different device sizes (mobile, tablet, desktop). Think of frames as your canvas for each page design.

3. Rectangle Tool (R)

Draw rectangles and squares. Use this for creating boxes, buttons, image placeholders, and layout sections. Hold Shift while dragging to create perfect squares.

4. Text Tool (T)

Add text to your design. Click anywhere to start typing. Use the properties panel on the right to change font, size, color, and alignment.

5. Pen Tool (P)

Draw custom shapes and paths. More advanced - you probably won't need this for basic website designs.

6. Color Fill

Select any shape, then use the Fill section in the properties panel (right side) to change its color. You can use:

  • Solid colors
  • Gradients
  • Images (drag and drop)

Designing Your Silverlake Theme Park Site

Start with Your Wireframes

Your wireframes from last week show the structure and layout. Now you'll add the visual design:

Converting Wireframes to Figma Designs

  1. Import your wireframes: Take photos of your hand-drawn wireframes and drag them into Figma as reference images. Lock the layer so you don't accidentally move them.
  2. Create frames: Create a mobile frame and desktop frame for your homepage
  3. Build the layout: Use rectangles to create the main sections (header, hero, attractions grid, footer)
  4. Add content: Insert text, placeholder images, and buttons
  5. Apply styling: Add colours, fonts, spacing, and visual polish

Choosing Colours for Your Theme Park

Your colour scheme should match the theme and mood of your park. Consider:

  • Fantasy/Magical: Purples, golds, deep blues
  • Adventure/Jungle: Greens, browns, earthy tones
  • Futuristic/Sci-fi: Blues, silvers, neon accents
  • Water Park: Blues, aquas, sandy yellows
  • Historical: Muted tones, browns, aged colors

Color Palette Tools

Use these free tools to create color schemes:

  • Coolors.co - Generate color palettes
  • Adobe Color - Create and explore color schemes
  • Paletton - Color scheme designer

Tip: Choose 2-3 main colours plus neutral colors (white, gray, black)

Typography - Choosing Fonts

Fonts communicate personality. For your theme park website, you'll need:

  • Heading Font: Bold, attention-grabbing (for titles and headers)
  • Body Font: Readable, clean (for paragraphs and descriptions)

Finding Fonts

Figma includes Google Fonts. Popular combinations:

  • Modern & Clean: Montserrat (headings) + Open Sans (body)
  • Elegant: Playfair Display (headings) + Lato (body)
  • Fun & Friendly: Poppins (headings) + Roboto (body)
  • Bold & Impactful: Bebas Neue (headings) + Raleway (body)

Rule: Don't use more than 2-3 different fonts in your design

Adding Images

You can add images to your Figma design in several ways:

  1. Drag and drop: Drag image files directly onto your frames
  2. Fill images: Create a rectangle, then in the Fill section, click the image icon and select an image
  3. Placeholder images: Use rectangles with an X through them (just like wireframes) until you have final images

Free Stock Photo Sources

  • Unsplash

Search for: "roller coaster", "theme park", "amusement park", "adventure", etc.

Mobile-First Design in Figma

Remember the mobile-first philosophy from last week? Apply it in Figma:

  1. Start with mobile: Design your mobile layout first
  2. Simplify: Use single columns, larger touch targets, hamburger menu
  3. Then expand: Create your desktop version by duplicating and adapting the mobile design
  4. Add complexity: Desktop can have multi-column layouts, more visible navigation, etc.

Responsive Design Tips

  • Keep the same colour scheme and fonts across both versions
  • Content should be the same, just arranged differently
  • Mobile: Stack vertically, Desktop: Use columns and grids
  • Make sure text is readable on both (minimum 16px for body text)

Homework - Design Your Silverlake Site in Figma

This week's homework is to create a complete design for your Silverlake Theme Park website in Figma.

Task 1: Set Up Your Figma Project

  • Create a free Figma account (if you haven't already)
  • Create a new design file called "Silverlake Theme Park Design"
  • Create at least 2 frames:
    • Mobile frame (e.g., iPhone 14 Pro - 393 x 852)
    • Desktop frame (e.g., Desktop - 1440 x 1024)

Task 2: Design Your Homepage

Using your wireframes as a guide, create polished designs for both mobile and desktop versions of your homepage:

Required Elements:

  • Header with logo/site name and navigation
  • Hero section with eye-catching image and headline
  • Featured attractions section (grid of attraction cards)
  • About/welcome section
  • Footer with contact info and links

Design Requirements:

  • Choose and apply a colour scheme (2-3 main colours + neutrals)
  • Select appropriate fonts (1 for headings, 1 for body text)
  • Add placeholder images or stock photos
  • Ensure consistent spacing and alignment
  • Make the design match your theme park's theme and personality

Task 3: Export Your Design

Once your design is complete:

  1. Take screenshots of your mobile and desktop designs
  2. Export them as PNG or JPG files (File → Export)
  3. Save them for your Planning Document
  4. Get the shareable link to your Figma file (Share button, top-right)

Tips for Success

  • Start simple - don't try to make everything perfect on the first try
  • Look at real theme park websites for inspiration
  • Use the video tutorials linked above if you get stuck
  • Save your work regularly (Figma auto-saves, but check occasionally)
  • Ask for feedback from classmates or tutors
  • Remember: This design will guide you when you code the actual website
